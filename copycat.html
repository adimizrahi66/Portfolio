Overview

Overview

CopyCat is an integrated content and ad-generation platform designed to streamline digital marketing workflows through a unified ecosystem — spanning production & layout, creative assets, and optimization & insights.

It combines an Articles Generator to manage queues and page structures, a prompt-powered Banner Generator with a modular JSON template library, and analytics tools like Winner Discovery, an Image Library, and a BI Dashboard tracking production metrics and asset performance.

Challenge →

To scale acquisition on Meta, the growth team faced the operational burden of generating 500 new creative assets daily across parallel campaigns — a production bottleneck that stalled their scaling targets.

Strategy →

Build a custom platform tailored to the growth team's needs. Unify disparate tools under one roof and integrate advanced AI to consolidate the entire workflow into a single, streamlined ecosystem.

Results →

A semi-automated workflow for rapid creative and landing-page generation cut content production time by 75% compared to the previous process — enabling the team to scale efficiently.

Defining the Problem

How can we unify all the tools into one smooth workflow?

The team managed a fragmented workflow, using more than 6 different tools simultaneously to create an average of 30 landing pages a day. The production cycle jumped across Google Sheets, Asana, Gemini, Ideogram, the Kueez CMS, and an old vibe-coded version of CopyCat.

To find out where the friction lived, I began by mapping the entire user journey and auditing every single action taken throughout the existing production cycle — pinpointing the exact points where time and momentum were lost.

6+ Disconnected Tools: Every asset required jumping between spreadsheets, task boards, AI tools, and a CMS — with no shared source of truth.
The Copy-Paste Tax: Users manually transcribed titles, storefront links, and PIDs between tools — a constant source of errors and lost time.
Volume Bottleneck: The manual process couldn't sustain the creative volume and data velocity required to hit aggressive scaling targets.
Strategy & Exploration

User Flow Mapping

I mapped the entire user journey across the six-tool production cycle. Understanding this journey provided the blueprint for building a centralized, automated platform that replaced six disconnected steps and dozens of manual actions with one continuous flow.

Google Sheets → Asana → Gemini → Ideogram → Kueez CMS → CopyCat (old). Six tools, one fragile chain. The goal: collapse it into a single, cohesive flow.

Product Context

CopyCat started as a rough, developer-built prototype that helped creatives generate assets but was too complex and isolated for other departments. I transformed this initial iteration into a holistic, end-to-end platform that harmonizes workflows across the entire ecosystem.

Design Solutions

Anchoring the flow around the task list

Using my user journey map to prioritize features, I realized that every production cycle originated from an Asana task list. Each row contained the foundational data critical to the entire workflow — from landing-page generation to the specific creative assets tied to them.

Migrating the content tasks list

I anchored the entire creation flow around a centralized task list inside CopyCat. By migrating and mirroring the familiar structure of Asana within the new platform, I minimized the user learning curve and drastically reduced cognitive load.

Connecting Articles & Creatives creation flow

Next I mapped the functional dependencies between landing pages and creative assets within each task row. Different actions required specific data inputs — Landing Page Generation needs a storefront link and a page title; Creative Asset Generation needs a Product ID (PID).

Because a PID is only generated after an article goes live, the workflow requires a strict sequence. I designed a unified interface that structurally enforces this dependency while keeping all data, statuses, and generated assets in a single, cohesive view.

Connecting Data to Actions

The redesigned task row introduces contextual action buttons for "Article" and "Creatives." To enforce the sequence, the "Creatives" button stays disabled until the landing page is generated and a PID is live. Once active, the system unlocks the button and automatically passes the PID and metadata directly into the creative generation pipeline.

The Friction: Users previously spent time manually copying titles, storefront links, and new PIDs between Asana and disconnected creation utilities.
The Solution: Data fields now sync natively within the row, eliminating manual transcription errors and ensuring data continuity.
Automating this extraction eliminated 5 manual clicks per task — drastically reducing workflow friction and human error.

Streamlining Article Creation

Clicking "Article" opens a modal that instantly syncs the page title. Integrated AI models automatically pre-populate the body copy and banner image, letting the user simply review the layout and hit "Create."

The Friction: Users previously jumped between external AI tools to prompt copy, extract text blocks, and manually upload images into a separate CMS.
The Solution: Automating the initial layout and pre-populating fields eliminated six manual clicks per page and cut production time significantly.

Once the article goes live, the Creatives button activates instantly. The user can immediately click through to start generating ad assets, maintaining total momentum without switching contexts.

The Multi-Step Creative Flow

Clicking the Creatives button launches a guided, step-by-step wizard designed to balance automation with human oversight. To prevent errors, each step isolates a crucial decision point. Advanced automation handles asset rendering and data population, while the interface highlights only the critical variables requiring human approval.

Balancing Automation with User Control

When a user finishes the creative workflow, the task row turns green to signal completion. I intentionally left the final "check" manual. This high-sensitivity process requires a curated human review; giving users final sign-off reduces anxiety, provides a sense of control, and prevents the friction of automated errors.

Results

The Impact

By unifying six disconnected tools into one continuous flow and layering AI automation over the manual steps, CopyCat consolidated the entire production cycle into a single, streamlined ecosystem. The semi-automated workflow let the growth team generate creatives and landing pages at the volume their scaling targets demanded — without adding headcount.
